# Drop N Launch — Trevor Design

Vue marketing site prototype for Drop N Launch.

## Run

```bash
cd dropnlaunch-trevor-design
npm install
npm run dev
```

## Notes

- Light, Dude Perfect–leaning palette with brand green `#76CE00`
- Reuses App Store / Google Play badges and home-plate mark from `dropnlaunch-site-redesign`
- Image placeholders live in `public/assets/` — swap paths when real photos are ready
- Routes: `/` (Home), `/get-started`
